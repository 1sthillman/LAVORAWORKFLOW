# LAVORAWORKFLOW

Lavora Design Çalışma Masası - Proje ve İş Akışı Yönetim Uygulaması

## 🚀 Özellikler

- ✅ **Basılı Tutma İle Onaylama**: İş akışında "Tamam" butonlarına 1.2 saniye basılı tutarak smooth bir şekilde onaylama
- 📊 **Proje Yönetimi**: Excel, CSV ve fotoğraftan tablo oluşturma
- 🔄 **İş Akışı Takibi**: Aşamalı ürün takibi ve ilerleme yüzdesi
- 💰 **Masraf Defteri**: Gelir-gider takibi (KDV sadece defterde)
- 📱 **Mobil Uyumlu**: Responsive tasarım, offline çalışma
- 🎨 **Modern UI**: Smooth animasyonlar ve kullanıcı dostu arayüz

## 📦 Kullanım

Uygulama tamamen tarayıcıda çalışır, kurulum gerektirmez:

1. `lavora-calisma-masasi-v16.html` dosyasını tarayıcıda açın
2. Veya GitHub Pages üzerinden: https://1sthillman.github.io/LAVORAWORKFLOW/lavora-calisma-masasi-v16.html

## 🔧 Teknolojiler

- Vanilla JavaScript
- IndexedDB (Offline Storage)
- ExcelJS (Excel İşlemleri)
- Responsive CSS

## 📝 Değişiklikler (v16)

- ✨ İş akışında basılı tutma ile onaylama özelliği
- 🎯 KDV mantığı projelerden kaldırıldı (sadece defterde)
- 💫 Modern animasyonlar ve smooth geçişler
- 🎨 Daha eğlenceli ve kullanıcı dostu arayüz
